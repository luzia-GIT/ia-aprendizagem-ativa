# IA como ferramenta de aprendizagem ativa

## Como aprender melhor utilizando Inteligência Artificial

> **“Não quero apenas aprender a perguntar melhor para a IA. Quero aprender a utilizar a IA para aprender melhor.”**

## Sobre o projeto

Este projeto investiga como a Inteligência Artificial pode ser utilizada não apenas para fornecer respostas, mas também como uma ferramenta de **aprendizagem ativa**.

A proposta é experimentar diferentes formas de interação com a IA, utilizando a engenharia de prompts, e observar como essas mudanças podem influenciar a compreensão de um determinado conteúdo.

O projeto foi desenvolvido como parte de um desafio da **DIO**, utilizando o **NotebookLM** como ferramenta de apoio aos experimentos.

## Problema

A facilidade de obter respostas prontas por meio da Inteligência Artificial pode ajudar no aprendizado, mas também pode fazer com que o estudante apenas receba informações sem realmente elaborar o conhecimento.

A questão central deste projeto é:

> **Como utilizar a Inteligência Artificial para favorecer uma aprendizagem mais ativa, na qual o estudante compreenda, reflita e consiga explicar o conteúdo com suas próprias palavras?**

## Hipótese

A hipótese explorada neste projeto é que **prompts estruturados para aprendizagem ativa podem favorecer uma maior participação do estudante no processo de aprendizagem**, quando comparados a prompts que apenas solicitam respostas.

Este projeto é um experimento exploratório individual e, portanto, seus resultados não devem ser considerados uma comprovação científica.

## Metodologia

Para investigar essa hipótese, foram realizados três experimentos utilizando o mesmo tema:

**Agentes de Inteligência Artificial.**

### Teste A — Prompt simples

Solicitação direta de uma explicação.

Objetivo: observar como a IA responde a uma pergunta sem contexto adicional.

### Teste B — Prompt contextualizado

A IA recebeu informações sobre:

- seu papel;
- o perfil do estudante;
- o nível de conhecimento;
- a necessidade de utilizar exemplos;
- a necessidade de estabelecer comparações.

Objetivo: observar se um prompt mais estruturado produz uma explicação mais adequada ao aprendizado.

### Teste C — Aprendizagem ativa

A IA foi configurada como um tutor.

Em vez de apresentar imediatamente uma resposta completa, ela deveria:

1. fazer perguntas;
2. verificar o conhecimento prévio;
3. identificar acertos e lacunas;
4. propor novas perguntas;
5. estimular a elaboração do estudante;
6. apresentar uma síntese depois das tentativas.

Objetivo: observar se a interação ativa favorece a capacidade de explicar o conceito com as próprias palavras.

## Evolução da aprendizagem

Durante os experimentos, minha compreensão sobre agentes de IA passou por diferentes etapas.

Inicialmente, compreendi o agente como uma espécie de **“gerente de comandos”**, capaz de organizar e executar tarefas.

Depois, passei a compreendê-lo como um **sistema que age em direção a um objetivo**, utilizando modelos de linguagem, mecanismos de raciocínio e ferramentas externas.

No terceiro experimento, consegui representar o funcionamento de um agente por meio de um ciclo:

**Planeja → Age → Verifica → Ajusta → Repete até alcançar o objetivo.**

Essa evolução foi registrada no projeto como parte das chamadas **“cicatrizes de aprendizagem”**.

## Cicatrizes de aprendizagem

As dificuldades, dúvidas, reformulações e correções encontradas durante os experimentos não foram descartadas.

Elas fazem parte do processo.

As cicatrizes registram:

- o que eu compreendi inicialmente;
- onde encontrei dificuldades;
- como a IA contribuiu;
- quais conceitos precisei revisar;
- como reformulei minha compreensão;
- quais limitações identifiquei nas respostas da IA.

## Pensamento crítico

Um dos aprendizados do projeto foi perceber que uma resposta tecnicamente estruturada nem sempre é uma resposta pedagogicamente adequada.

Também foi necessário questionar algumas simplificações apresentadas pela IA, como a ideia de que todo chatbot apenas responde perguntas e que todo agente necessariamente funciona de maneira completamente autônoma.

Isso reforçou a importância de utilizar a IA como **ferramenta de apoio**, mantendo o estudante como protagonista do processo de aprendizagem.
