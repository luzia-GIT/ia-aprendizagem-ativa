# Introdução

## Inteligência Artificial e aprendizagem

A Inteligência Artificial está cada vez mais presente no processo de aprendizagem. Ferramentas capazes de explicar conceitos, resumir conteúdos, responder perguntas e auxiliar na pesquisa podem facilitar o acesso ao conhecimento.

Porém, ter acesso rápido a uma resposta não significa necessariamente ter aprendido.

Este projeto parte justamente dessa reflexão.

## O problema

Quando utilizamos uma ferramenta de Inteligência Artificial, podemos simplesmente fazer uma pergunta e receber uma resposta pronta.

Esse processo é rápido e pode ser útil, mas existe uma questão importante:

> **Será que receber uma resposta é o mesmo que aprender?**

A partir dessa pergunta, surgiu o interesse em investigar diferentes formas de interação com a IA.

## Aprendizagem ativa

A aprendizagem ativa coloca o estudante em uma posição mais participativa.

Em vez de apenas receber informações, o estudante é estimulado a:

- pensar;
- responder;
- questionar;
- relacionar conceitos;
- identificar dúvidas;
- explicar ideias com suas próprias palavras;
- revisar sua compreensão.

Neste projeto, a Inteligência Artificial foi utilizada como uma ferramenta de apoio para estimular esse processo.

## Pergunta central

A investigação foi orientada pela seguinte pergunta:

> **Como utilizar a Inteligência Artificial para favorecer uma aprendizagem mais ativa?**

## Objetivo

O objetivo deste projeto é experimentar diferentes formas de interação com a Inteligência Artificial e observar como a estrutura dos prompts pode influenciar a experiência de aprendizagem.

Para isso, foram realizados três testes utilizando o mesmo tema:

**Agentes de Inteligência Artificial.**

A comparação entre os testes permitiu observar diferenças entre:

1. receber uma explicação;
2. receber uma explicação contextualizada;
3. participar de uma interação orientada para aprendizagem ativa.

## Reflexão inicial

O projeto também considera uma diferença importante:

**compreender uma explicação não significa necessariamente conseguir explicar o conceito com autonomia.**

Por isso, a capacidade de explicar o conteúdo com minhas próprias palavras foi utilizada como um dos indicadores da minha evolução durante os experimentos.
