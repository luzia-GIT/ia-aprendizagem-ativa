# Teste B — Prompt contextualizado

## 1. Objetivo

Observar se fornecer contexto, definir o papel da IA e indicar o nível de conhecimento do estudante contribui para uma explicação mais adequada à aprendizagem.

## 2. Prompt utilizado

> Atue como um professor de tecnologia. Explique o que é um agente de IA para um estudante iniciante. Apresente um exemplo cotidiano e diferencie um agente de IA de um chatbot tradicional.

## 3. Estratégia utilizada

O prompt apresenta três orientações principais:

* **Papel:** atuar como professor de tecnologia.
* **Contexto:** explicar para uma pessoa iniciante.
* **Formato:** apresentar um exemplo cotidiano e estabelecer uma comparação.

## 4. O que observar

* Se a linguagem ficou mais acessível.
* Se o exemplo facilitou a compreensão.
* Se a comparação ajudou a diferenciar os conceitos.
* Se consegui explicar o conteúdo com minhas próprias palavras.
* Se a resposta apresentou simplificações que precisam ser questionadas.

## 5. Registro do experimento

A resposta obtida no NotebookLM e minhas observações serão registradas no arquivo `experimentos/teste-b.md`.

**Nota:** o objetivo é comparar a resposta deste teste com a do Teste A, observando as diferenças sem presumir antecipadamente que uma estratégia será melhor.
